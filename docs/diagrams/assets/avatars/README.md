# Cast avatars

One avatar per character in [the cast](../../../architecture/cast.md). Each is a colored disc with a white emblem taken from the myth behind the name:

| Character | Emblem |
| --- | --- |
| Gökhan | A person: the product owner |
| Atlas | A figure holding up a globe |
| Argus | Many eyes, the watcher |
| Iris | The rainbow the messenger travels on |
| Daedalus | The wings the craftsman built |
| Cerberus | Three heads guarding the gate |
| Pythia | The oracle's tripod and its vapour |
| Echo | Sound waves, repeating what was said |

Original artwork for this repository, generated by [render_avatars.py](../../../../scripts/render_avatars.py); no third-party marks. Change an avatar there, run it, then run `render_diagrams.py`.
