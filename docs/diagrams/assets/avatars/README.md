# Cast avatars

One avatar per character in [the cast](../../../architecture/cast.md): a flat cartoon person on a disc in the character's color, with one prop for the role. The character names are labels; the avatars are ordinary people, not mythological figures.

| --- | --- |

| Iris | Coordinator: curly hair, headset with a microphone |

| Cerberus | CI gate: guard's cap, high-visibility vest |
| Pythia | Model server: silver pixie cut, dark turtleneck |

Original artwork for this repository, generated by [render_avatars.py](../../../../scripts/render_avatars.py); no third-party marks. Change an avatar there, run it, then run `render_diagrams.py`.
