# Cast avatars

One avatar per character in [the cast](../../../architecture/cast.md): a flat cartoon bust on a disc in the character's color, with one attribute from the myth behind the name.

| Character | Drawn as |
| --- | --- |
| Gökhan | A generic product owner with a check badge; not a likeness |
| Atlas | A bearded titan holding the globe above his head |
| Argus | A watcher with extra eyes on a golden headband |
| Iris | The messenger with a rainbow behind her and small wings at the temples |
| Daedalus | A bearded craftsman with workshop goggles and the wings he built |
| Cerberus | A friendly three-headed dog with a spiked collar |
| Pythia | A hooded oracle with a laurel wreath, eyes closed, vapour rising |
| Echo | A figure with a hand cupped at the ear, sound coming back |

Original artwork for this repository, generated by [render_avatars.py](../../../../scripts/render_avatars.py); no third-party marks. Change an avatar there, run it, then run `render_diagrams.py`.
