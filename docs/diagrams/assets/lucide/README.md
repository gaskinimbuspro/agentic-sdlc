# Lucide icons

Pinned commit: [`55782beff3a0133df79c417eb68f96e8f19e2404`](https://github.com/lucide-icons/lucide/tree/55782beff3a0133df79c417eb68f96e8f19e2404).

Retrieved: 14 November 2026.

This directory contains the SVG icons used by the diagrams. The generator applies color/size. GitHub is represented by a git-branch symbol.

[LICENSE](LICENSE) preserves the Lucide ISC notice and MIT notice for Feather-derived icons. The standalone diagrams also retain these notices in their metadata.

Added 17 November 2026 from the npm package `lucide-static` version 1.74.0 (ISC): `bot`, `circle-check`, `container`, `cpu`, `globe`, `hard-drive`, `lightbulb`, `lock`, `messages-square`, `pencil-ruler`, `route`, `square-kanban`. The package's license comment was removed from each file; the notice in [LICENSE](LICENSE) covers them. The earlier icons remain at the pinned commit above. On 21 November 2026 `copy`, `eye` and `hammer` were added from the same package version for the character icons.
